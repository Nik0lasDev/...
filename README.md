# THE PARALLEL — Predador

Jogo de ação e horror em visão superior, inspirado no universo de **The Parallel**, de LC. Aqui, você controla uma criatura e caça pela cidade para acumular essência, sobreviver à resposta humana e desbloquear novas formas.

## Jogar

O projeto é estático: não precisa de instalação nem de dependências.

- Abra `index.html` diretamente no navegador; ou
- Publique o repositório no GitHub Pages.

## Controles

| Tecla | Ação |
|---|---|
| WASD / Setas | Mover |
| Shift | Correr |
| Espaço ou clique | Atacar |
| Q | Habilidade da espécie |
| Esc | Pausar |

## Progressão

Comece como **Filhote Sombrio**, uma criatura original fraca. Cada humano caçado concede essência e contribui para desbloquear mutações. As escolhas alteram atributos, habilidades e os próximos ramos disponíveis.

### Criaturas e referências de The Parallel

O jogo incorpora formas e entidades conhecidas da série, incluindo **Bipedal Stalker**, **Quadrupedal Stalker**, **Tormentor**, **Despair Culler**, **Entity of Influence**, **Anguish** e o evento digital **Virus**. Também existem mutações originais criadas para ampliar a árvore de evolução.

As habilidades e a progressão são adaptações de gameplay, não uma reprodução literal de toda a lore.

## Sistemas

- Cidade procedural com quarteirões, edifícios, ruas e iluminação irregular.
- Humanos que caminham, entram em pânico, fogem e podem chamar reforços.
- Resposta policial que aumenta conforme a caça se torna mais evidente.
- Vida, fome, vigor, essência e habilidades com recarga.
- Árvore de evolução com escolhas divergentes.
- Interface adaptável para desktop e dispositivos móveis.

## Tecnologias

HTML, CSS e JavaScript puro com Canvas 2D. Sem bibliotecas externas, etapa de build ou dependências.

## Publicar no GitHub Pages

1. Abra **Settings → Pages**.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch `main` e a pasta `/ (root)`.
4. Salve e aguarde a publicação.

O workflow incluído também publica automaticamente o conteúdo estático quando há push na branch principal.

## Créditos e inspiração

**The Parallel** é uma série criada por **LC**. Este é um projeto de fã, não oficial, sem vínculo com o criador. Personagens, nomes e conceitos da série pertencem aos respectivos titulares. As criaturas e sistemas originais deste jogo foram criados para esta adaptação.
